### 🧭 How I Teach

I'm redesigning both courses around **AI-assisted workflows** — without skipping the fundamentals.

- **Foundation first.** Students earn AI tools by demonstrating real HTML/CSS literacy.
- **Authorship, not assistance.** Students own, understand, and can explain everything they ship.
- **A four-step loop:** 1) Define the behavior → 2) Direct the tool → 3) Evaluate the output → 4) Own the refinement.
- **Workshops over lectures.** Hands-on studio time, live critiques, and building real projects.
